# VoiceClear PWA 🎙️✨
> تطبيق ويب تقدمي (PWA) فائق السرعة والأناقة لتحويل وتفريغ رسائل الواتساب الصوتية إلى نص عربي فصيح ومنقح بالذكاء الاصطناعي مع إزالة الحشو والتأتأة والكحة.

---

## 🌟 المميزات الرئيسية

1. **دعم مباشر لصيغ الواتساب:** يتعامل تلقائياً مع صيغ `.opus` و `.ogg` و `.m4a` و `.wav` بالإضافة إلى إمكانية التسجيل المباشر من الميكروفون داخل المتصفح.
2. **تفريغ وتنقيح ذكي بالـ AI:** 
   - إزالة أي تردد، كحة، تهتهة، أو كلمات حشو (مثل: آآ، امم، يعني).
   - تصحيح زلات اللسان تلقائياً واستخلاص المقصد الفعلي للمتحدث (مثلاً: "هنروح يوم الأحد.. لأ قصدي الاتنين" ⬅️ "هنروح يوم الاتنين").
   - صياغة احترافية مع علامات الترقيم وتنسيق الفقرات.
3. **نظام 5-Stage Gemini Fallback فائق المرونة:**
   - يفحص الموديلات بالتسلسل المخصص:
     1. `gemini-3.8-flash` (الأساسي)
     2. `gemini-3.5-pro` (البديل الأول)
     3. `gemini-3.0-pro` (البديل الثاني)
     4. `gemini-2.5-flash` (البديل الثالث)
     5. `gemini-2.0-pro` (البديل الرابع)
     بالإضافة إلى بدائل الطوارئ لضمان عدم توقف الخدمة نهائياً.
4. **Offline First & صفر تكلفة سيرفرات:**
   - PWA قابل للتثبيت كأيقونة تطبيق على أجهزة Android و iOS و Desktop.
   - كاشينج ذكي للأصول باستخدام Workbox.
   - تخزين السجل محلياً بنسبة 100% على جهاز المستخدم عبر `IndexedDB`، وبدون أي قواعد بيانات خارجية (جاهز للنشر المجاني على Vercel).
5. **تصميم Stitch عصري ومريح للعين:**
   - Dark Theme فخم مع إضاءات Glassmorphism بدرجات الزمرد (Emerald / Teal).
   - أنيميشن تحميل مسلي باستخدام `Framer Motion` مع نصوص تفاعلية تحافظ على انتباه المستخدم.
   - نسخ فوري للحافظة مع إشعارات Sonner Toast، ومشاركة مباشرة للواتساب، وتنزيل بصيغة `.txt`.

## 🚀 التشغيل السريع

### 1. المتطلبات:
- Node.js 18 فما فوق.
- مفتاح Google Gemini API Key.

### 2. التثبيت والتشغيل:
```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev

# أو البناء للإنتاج
npm run build
npm start
```

### 3. إعداد متغيرات البيئة:
أنشئ ملف `.env.local` وضع فيه مفتاح Gemini الخاص بك:
```env
GEMINI_API_KEY=your_gemini_api_key_here
```
